# Тема 5 · Заняття 7 — Графічний дизайн візуалізації даних

Публічна інтерактивна навчальна вебсторінка: [Відкрити index.html](index.html).

## Вміст
Шість вкладок: Вступ, Принципи графічного дизайну, Демонстрація кейсів, Групова робота, Презентація рішень, Підсумки. Приклади використовують **синтетичні навчальні дані**. Графіки, перемикання кейсів і тест працюють у браузері без сервера та сторонніх бібліотек.

## Публікація через GitHub Pages
1. Відкрити репозиторій `lotoslena-maker/mi2024-1` → **Settings → Pages**.
2. У **Build and deployment** вибрати `Deploy from a branch`, гілка `main`, каталог `/(root)`, зберегти.
3. Після публікації відкривати сайт за адресою: `https://lotoslena-maker.github.io/mi2024-1/Theme5/GroupLesson57/`.
4. Перевірити публічне відкриття в режимі інкогніто **перед створенням QR-коду**.

Файл `index.html` самодостатній, його можна відкрити локально без інтернету. Окремий серверний Flask-проєкт для практики запускається локально та не працює на GitHub Pages.
